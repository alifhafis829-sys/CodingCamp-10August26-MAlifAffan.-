# Life Dashboard Specification

## Overview
A functional personal dashboard featuring a real-time clock, dynamic greeting, customizable username, focus timer with presets, task management (to-do list), quick links, and theme toggle (light/dark mode).

## Features & Requirements
1. **Clock & Greeting**
   - Real-time clock updating every second.
   - Dynamic greeting based on the time of day (Morning/Afternoon/Evening).
   - Editable username saved in `localStorage`.

2. **Focus Timer**
   - Presets for 25m, 15m, and 5m.
   - Start, Stop, and Reset controls.

3. **Task Management**
   - Add, edit, toggle complete, and delete tasks.
   - Task state persisted in `localStorage`.

4. **Quick Links**
   - Custom links with name and URL.
   - Stored in `localStorage`.

5. **Theme Toggle**
   - Light and Dark mode persistent via `localStorage`.
